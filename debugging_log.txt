CODE QUALITY IMPROVEMENT: FILE HANDLING

Original Code:
file = open("results.txt", "w")
file.write(name + "," + str(average) + "," + grade + "\n")
file.close()

Improved Code:
with open("results.txt", "w") as file:
    file.write(name + "," + str(average) + "," + grade + "\n")

Reason:
The with open() statement automatically closes the file after
the writing operation. This makes the code cleaner and safer.
